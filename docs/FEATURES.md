# Ported Features

OpenCode accepts `tool: opencode` and uses `opencode/deepseek-v4.1-flash-free` at every tier. Its prompt travels in a temporary UTF-8 file with `run --auto -f`, stdin is closed, and the file is removed after the call or dry run. Reviewers are AGY then Claude. `ANDY_NO_OPENCODE_REPOS` supplies blocked roots separated by `os.pathsep`, using the private within-directory check instead of its trading path.

Builder mode reads `builder_mode` in `state_dir()`. Line one selects `claude`, `codex`, or `gemini` (AGY); an optional ISO reset on line two expires it. It overrides the builder after the first cooldown fallback, except for OpenCode, then checks cooldown again. Codex mode saves Claude; Claude and Gemini modes save Codex. Reviews skip the saved family if another reviewer remains, and stuck diagnosis switches away from that family. The copied reviewer selection also puts AGY before Codex for Claude final reviews, while plan checks keep Codex first.

Save-Claude reads the first line of `save_claude` in `state_dir()`. Missing files are off, empty or invalid reset values are on, and an ISO reset expires the switch. It steers unpinned Claude builds to Codex, moves Claude reviews last, and changes stuck diagnosis. Unlike the spec's restriction on encoding handling, the private code already reads both switch files with UTF-8 BOM support and warns once for undecodable files, treating them as off; this behavior is preserved. Builder mode also retains the private inline timezone comparison logic. `state_dir()` uses `ANDY_STATE_DIR` when set, otherwise `Path.home() / ".andy_sync"`, including for run reports and cooldown state.

Tool cooldown records a builder's `RuntimeError` containing `spend cap` or `usage limit` in `tool_cooldown.json` for five hours. Loading removes expired entries. Before building, a capped tool falls back to Claude then AGY if available under cooldown and saved-family restrictions. Reviews filter capped tools but retain their original list when all are capped; an unreadable cooldown file is ignored only in reviewer selection. Builder failures are recorded and re-raised, without an immediate retry.

Process-tree timeout handling is copied into `run_tree.py` and used by the AGY classification call in `llm_router.py`, the only use in the supplied private runner files. On timeout it runs Windows `taskkill /T /F`, or kills the direct process on other platforms, drains output, and re-raises the timeout. The routing call returns `None` on timeout as before.
